### V3.3.44.5 查詢穩定性修正

縮短行情備援的逾時上限：上櫃 range 18 秒、每個月來源 8 秒，籌碼與基本面每個来源 5 秒，避免原本 25 + 45 + 15 秒超過前端 75 秒期限。既有行情與位點公式保持不變。連續切换個股只接受最後一次查詢結果；網站腳本與樣式使用版本網址，Service Worker 禁用更新快取。最新行情的日期驗證以台北最近完成收盤日為基準，避免開盤後與 UTC 日期不一致。

### V3.3.44.6 多檔掃描資源隔離

多檔掃描改由瀏覽器逐檔送出独立請求，最多兩檔並行，逐筆顯示進度和結果。後端單次掃描只接受一檔，避免最差備援累積超出每次請求的外部查詢與 CPU 限制。一檔失敗保留其他結果；新掃描開始後，舊掃描不能覆蓋結果。掃描共用完整分析流程與行情快照，接受基準日及計算模式，避免掃描和完整分析取得不同資料。
