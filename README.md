### V3.3.44.5 查詢穩定性修正

縮短行情備援的逾時上限：上櫃 range 18 秒、每個月來源 8 秒，籌碼與基本面每個来源 5 秒，避免原本 25 + 45 + 15 秒超過前端 75 秒期限。既有行情與位點公式保持不變。連續切换個股只接受最後一次查詢結果；網站腳本與樣式使用版本網址，Service Worker 禁用更新快取。最新行情的日期驗證以台北最近完成收盤日為基準，避免開盤後與 UTC 日期不一致。

### V3.3.44.6 多檔掃描資源隔離

多檔掃描改由瀏覽器逐檔送出独立請求，最多兩檔並行，逐筆顯示進度和結果。後端單次掃描只接受一檔，避免最差備援累積超出每次請求的外部查詢與 CPU 限制。一檔失敗保留其他結果；新掃描開始後，舊掃描不能覆蓋結果。掃描共用完整分析流程與行情快照，接受基準日及計算模式，避免掃描和完整分析取得不同資料。

### V3.3.44.7 多檔掃描表格

掃描結果以股票名稱、現價及隔日核心位點呈現，每檔兩列，主價下方以全形括號顯示價格帶，名稱欄第二列留白。縮小數字字體與兩列間距，手機可橫向捲動並固定名稱欄；點股票名稱仍可開啟完整分析。掃描 API 傳回完整位點與價格帶，條件顯示第一／中期壓力，突破共振存在時不另列同檔第一壓力。保留逐檔請求、進度與個別錯誤顯示。

### V3.3.44.8 照片七點規則

將照片可辨識的規則接入個股、回測及掃描共用計算流程：只由歷史結構候選選位點，均線及整數價不能單獨形成或串接結構；依原始錨點容差合併，選最近且互不重疊的價格帶。主價與上下界依股票升降單位校準。支撐0–10%近端、>10–20%中期、>20%只列遠端觀察。下一個獨立壓力主價>10%改列中期，近端第二壓力留白。突破共振仍取代第一壓力；有真實第一壓力而沒有第二時可保留第一。照片推定模式保留已校準的壓力錨點，再套用相同命名與校準規則。

歷史資料不足以明確錯誤停止計算；資料足夠但沒有位點顯示「尚未形成」。創收盤歷史新高且沒有上方结构時，另列收盤價×1.10向下對齊合法跳動的理論漲停參考，註明非結構價位及實際價格須依交易所基準。本功能不聲稱已核對隔日除權息或特殊交易限制。波動容差沿用本系統1.25%，原圖未揭示唯一公式；照片推定模型仍清楚標示推定。
