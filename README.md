V3.3.45：依使用者提供的 2026/10/5 收盤參考圖校正（預估 10/6）。
- 普通支撐／壓力只找近60個交易日、現價±10%內的 OHLC 真實結構。確認樞紐使用左右各2根K棒，容許等高／等低平台；右側資料不得超過基準日。
- 第一支撐優先取下方最近前高轉支撐或未回補向上缺口，無則取樞紐低點。第二支撐比較下一個独立前高／缺口與最近40日最近一次較低樞紐低點，取較高者；價格帶不得重疊。
- 上方樞紐高點若曾被後續收盤突破，不再列原壓力；跌破的樞紐低點可轉為壓力。上下缺口必須尚未完全回補，星號表示缺口邊界、待回測確認。
- 同類樞紐聚合距離0.3%；缺口不混入普通樞紐帶，同價時缺口優先。第一壓力可單獨存在；第二壓力找下一個不重疊結構，無則回傳空值。最新參考圖的單一壓力優先於舊版必須成組要求。
- 關鍵突破暫定獨立證據：現價上方4%內、不同K棒的已確認樞紐高點與未回補向下缺口邊界相距不超過0.3%；成立後第一／第二壓力清空，中期壓力從其上方、距現價至少10%的真實樞紐另取。這項公式是推定規則，參考圖沒有關鍵突破欄，尚未驗證等同原系統。
- 月資料請求有15秒逾時；使用最近5個月資料，隔日驗證範圍不超過台灣已完成收盤日；資料不足65日或過期時停止計算。
- `tests/references/2026-10-05.json` 是人工轉錄的使用者圖片；`tests/fixtures/2026-10-05` 是官方行情轉送服務取得的截止基準日快照。執行 `node scripts/calibrate-reference.cjs tests/references/2026-10-05.json tests/fixtures/2026-10-05 public/calibration/2026-10-05.json` 可重現比對；引擎不讀取參考價位。
- 本校正樣本：72/72數值落於參考價格帶、28/28空值一致、9/9缺口星號一致；完整價格帶99/100欄一致，豐達科第二壓力124與參考124–125仍有差異。此為同一樣本校正後比對，不是獨立樣本驗證，也不是隔日行情正確率。

V3.3.46：新增 IMG_6667 六檔區間參考的獨立模式。
- 60日位點模式保留：原25檔數值100/100欄一致、完整價格帶99/100一致，豐達科124–125差異仍在。新圖有另一組回看／權息／區間規則，不以個股代碼切換公式。使用者可選182日曆日或182交易日區間；圖上未指定單位，兩種解讀對此次六檔皆相同。
- 區間只用基準日以前行情及基準日前生效的權息事件。以官方除權息參考價／前收盤價逐次累乘調整事件以前OHLC；最後基準日行情不變。官方查詢失敗時只可使用覆盖整段日期的權息快照，超出快照範圍須標記未取得，不默認已調整。此資料未涵蓋減資／分割，調整方式亦未證實等同原圖。
- 最新未回補向上缺口用前高至本日低點形成區間；同價歷史前高区可補足下緣。歷史前高的上影線區域可轉支撐；區間過寬時以其前一根高點界定近端區域。新高而歷史支撐過遠，使用最新K線低點與前高的重疊觀察區並標記†。
- 第二支撐區需整段低於第一區間。新缺口形成時，優先近期已確認低點與其右側2根形成的1.5%內低點／K棒實體邊緣區；反覆測試至少4次且至少2種低點、跨度0.5%內的較近底部可優先。無近期底部時，比較前一根低點與1.5%內較高歷史前高；最新K線觀察區的第二支撐優先用前一根下緣。普通前高區可與相距1.25%內歷史／前一根高點合併。上述為推定規則，不是從原系統取得的公式。
- 壓力以歷史確認高點上影線與跌破前低的實體邊緣區建立；區間重疊時避免重複列不同壓力。最新K線高點高於收盤且近3根創高時，加入帶†的待確認觀察位。第二壓力取整段高於第一區間的下一個独立區，不強制±10%截斷。†與缺口＊具有不同含義。
