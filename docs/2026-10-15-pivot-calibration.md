# 2026-10-15｜10/14 → 10/15 圖片校正

本次只校正「台股共振系統」。

## 已確認的新計算邏輯

使用者提供的第二張 10/14 預估 10/15 表格中，1615 大山、3167 大量、3564 其陽、3265 台星科、2886 兆豐金、4979 華星光四個位點完全符合經典 Floor Pivot：

- P = (H + L + C) / 3
- S1 = 2P - H
- S2 = P - (H - L)
- R1 = 2P - L
- R2 = P + (H - L)

圖片值：

| 代號 | S1 | S2 | R1 | R2 |
|---|---:|---:|---:|---:|
| 1615 | 52.70 | 50.70 | 55.70 | 56.70 |
| 3167 | 942.67 | 925.33 | 985.67 | 1011.33 |
| 3564 | 71.93 | 69.67 | 75.73 | 77.27 |
| 3265 | 269.50 | 246.50 | 304.00 | 315.50 |
| 2886 | 50.63 | 50.17 | 51.33 | 51.57 |
| 4979 | 550.67 | 513.33 | 606.67 | 625.33 |

六檔皆滿足 `R1 - S1 = H - L`、`R2 = P + (H-L)`、`S2 = P - (H-L)`；因此可確認這批並非既有的歷史結構選位，而是前一交易日 H/L/C 的 Pivot 算術。

## 正式校正策略

新增 `src/main.js` 包裝現有引擎，不改掉既有結構候選、ATR 壓力合併、AV 突破校正。

Pivot 僅能：
1. 使用 D 日 high / low / close；不得讀取 D+1。
2. 對已經形成的 support1 / support2 / breakout-or-resistance1 / resistance2-or-mediumResistance 做主價交叉校正。
3. Pivot 價必須位在既有結構價格帶內，或最多相鄰一個合法跳動單位。
4. 不得單獨創建新位點、不改支撐壓力角色、不用圖片目標數值當計算輸入。
5. 圖片中的 Pivot 原始小數保留在 `analysis.classicPivot` 稽核欄；正式主價仍依台股合法跳動單位校準。

這樣可把已確認的 10/14 Pivot 邏輯納入共振，而不把六檔圖片硬編碼成例外，也不破壞 No-look-ahead。
